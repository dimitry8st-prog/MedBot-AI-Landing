# Vitalis Skills — Сценарии для медицинского ассистента

Эта папка содержит навыки (skills) для медицинского AI-ассистента Vitalis.

## Файлы

### `vitalis-faq.md`

**Назначение:** FAQ-сценарии и роутинг запросов для медицинского чат-бота.

**Содержание:**
- Приветствия и описание возможностей системы
- Обработка технических вопросов («Как работает?», «Откуда данные?»)
- Роутинг немедицинских запросов (политика, развлечения, программирование и т.д.)
- Обработка опасных/неэтичных тем
- Примеры правильных и неправильных ответов

**Как использовать:**

1. **Claude Code skill** — скопируйте в `~/.claude/skills/` для использования в Claude Code
2. **Промпт-инжиниринг** — используйте шаблоны ответов в system prompt
3. **Intent classification** — используйте для определения типа запроса
4. **Тестирование** — таблица примеров для проверки качества ответов

**Пример интеграции:**

```python
# Загрузка шаблонов из skill
with open('docs/skills/vitalis-faq.md') as f:
    skill_content = f.read()

system_prompt = f"""
Ты — медицинский ассистент Vitalis для врачей.

{skill_content}

Следуй этим сценариям при ответе на запросы пользователя.
"""
```

## Принципы работы Vitalis

1. **Строгие границы компетенции** — только медицинские данные и клинические рекомендации
2. **Актуальность данных** — приоритет источникам 2023–2026, веб-поиск важнее устаревшего RAG
3. **Профессиональный тон** — обращение «коллега», ориентация на врачей и студентов
4. **Безопасность** — отказ от диагностики конкретных пациентов, только справочная информация

## Структура ответов

Каждый сценарий включает:
- **Триггеры** — ключевые фразы пользователя
- **Шаблон ответа** — готовый текст для использования
- **Примеры** — правильные и неправильные варианты

## Расширение skills

При добавлении новых навыков:
1. Создайте файл `{название}-skill.md` в этой папке
2. Используйте frontmatter для метаданных (name, description, whenToUse)
3. Структурируйте контент по сценариям
4. Добавьте примеры использования
5. Обновите этот README
