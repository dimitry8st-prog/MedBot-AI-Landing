# Артериальная гипертензия (I10)

## Диагностика (Д)

- Офисное АД, суточное мониторирование при необходимости
- Стратификация сердечно-сосудистого риска
- Обследование органов-мишеней: ЭКГ, креатинин/СКФ, липиды, глюкоза

## Лечение (Л)

- Модификация образа жизни
- ИАПФ/БРА, БКК, тиазидные/тиазидоподобные диуретики, β-блокаторы по показаниям
- Комбинации с фиксированными дозами для приверженности
- Целевое АД индивидуально, обычно < 140/90 с дальнейшей титрацией

## Реабилитация (Р)

- Самоконтроль АД
- Снижение соли, вес, физическая активность
- Диспансерное наблюдение
