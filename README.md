# MedBot AI — Landing

Отдельный фронтенд-лендинг для платформы **MedBot AI**.

Основной репозиторий (backend, RAG, Telegram-бот):  
https://github.com/dimitry8st-prog/MedBot-AI

## Запуск

```bash
npm install
npm run dev
```

Откроется: http://127.0.0.1:3000/

## Стек

- React + TypeScript
- Vite
- Tailwind CSS
